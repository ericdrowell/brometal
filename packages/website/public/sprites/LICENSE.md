# Sprite licenses

Every sprite atlas in this directory was created and distributed by
**[Kenney](https://kenney.nl)** and is licensed under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain).
Attribution is not required by the license; we credit Kenney anyway, in every
demo that draws these sprites and here.

The files are the `_packed` tilemaps from each pack, copied verbatim — no
resizing, recolouring, or re-packing. Tiles are laid out with no padding, so a
tile index maps to a grid cell by plain integer division (see
`src/lib/sprites.ts`).
